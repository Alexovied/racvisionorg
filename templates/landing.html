{% if en %}How it works{% else %}Cómo funciona{% endif %}

{% if en %}Three checks, one alert.{% else %}Tres controles, un solo aviso.{% endif %}

{% if en %}It finds every person in the frame, checks the head and the torso separately and confirms over 8 frames before alerting, so a single doubtful frame does not set off the alarm.{% else %}Encuentra a cada persona en la imagen, revisa la cabeza y el torso por separado y confirma con 8 frames antes de avisar, para no alertar por un frame dudoso.{% endif %}

01
{% if en %}

Sees the hard hat from any angle

{% else %}

Ve el casco desde cualquier ángulo

{% endif %}

{% if en %}A YOLOv8n detector finds heads with and without hard hats from the front, the side or the back, even when the face is not visible.{% else %}Un detector YOLOv8n encuentra cabezas con y sin casco de frente, de costado o de espaldas, aunque no se vea la cara.{% endif %}

02
{% if en %}

Checks the vest on every torso

{% else %}

Revisa el chaleco en cada torso

{% endif %}

{% if en %}A second model, combined with a high-visibility color rule, recognizes vests even when the person is seen from the side.{% else %}Un segundo modelo, combinado con una regla de color de alta visibilidad, reconoce el chaleco aunque la persona esté de costado.{% endif %}

{% if en %}Why it matters{% else %}Por qué importa{% endif %}

533

{% if en %}workers died in Peruvian mining between 2007 and 2025. Almost 6 in 10 died in accidents linked to hard hats or vests.{% else %}trabajadores murieron en la minería del Perú entre 2007 y 2025. Casi 6 de cada 10, en accidentes ligados al casco o al chaleco.{% endif %}

{% if en %}PPE only works if it is worn all the time, and checking by eye is intermittent. RAC Vision watches without getting tired. It does not replace ground support or procedures: it is one more layer of prevention.{% else %}El EPP sirve solo si se usa todo el tiempo, y el control a ojo es intermitente. RAC Vision mira sin cansarse. No reemplaza el sostenimiento ni los procedimientos: es una capa más de prevención.{% endif %}
